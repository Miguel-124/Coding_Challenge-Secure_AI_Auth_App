# 🛡️ Secure AI Auth App - Generator Wyzwań Kodowania

## 🌟 Opis Projektu
**Secure AI Auth App** to zaawansowana aplikacja full-stack stworzona w ramach wyzwania kodowania, zaprojektowana do dynamicznego generowania pytań rekrutacyjnych z kodowania przy użyciu sztucznej inteligencji.

Aplikacja zapewnia pełny cykl życia użytkownika, od bezpiecznej **autoryzacji** po **trwałe zapisywanie** wygenerowanych danych. Użytkownicy logują się za pomocą **Google (Clerk Auth)**, a następnie mogą generować wyzwania o poziomie trudności: **łatwym, średnim lub trudnym**, dzięki integracji z **ChatGPT**.

## 🛠️ Stos Technologiczny (Tech Stack)

Projekt został zbudowany przy użyciu nowoczesnego i wydajnego stosu:

### 💻 Frontend (Klient)
* **React**
* **JavaScript**

### 🐍 Backend (Serwer API)
* **Python**
* **FastAPI** (Wysokowydajny framework do budowania API)

### 💾 Baza Danych i Autoryzacja
* **SQLAlchemy:** ORM (Object-Relational Mapper) do zarządzania danymi i ich trwałością.
* **Clerk Auth:** Rozwiązanie do bezpiecznej autoryzacji i obsługi logowania Google.

### 🤖 Integracja AI
* **OpenAI API (ChatGPT):** Wykorzystywane do generowania dynamicznej treści wyzwań.
